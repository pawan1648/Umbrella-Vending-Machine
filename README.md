☔ Smart Vending Machine

A web-based Smart Vending Machine mini project developed using HTML, CSS, and JavaScript.  
This system simulates a real-world vending machine that provides weather-related products like umbrellas and raincoats.

📌 Project Overview

Sudden weather changes often create inconvenience for people.  
This Smart Vending Machine solves that problem by allowing users to quickly purchase essential weather items like umbrellas and raincoats through an interactive web interface.

It simulates:
- Product selection
- Quantity control
- Payment system (QR/Card simulation)
- Automatic dispensing process

🎯 Objectives

- Develop a smart vending machine using web technologies
- Provide weather-related products instantly
- Create a responsive and interactive UI
- Implement JavaScript-based logic for machine workflow
- Simulate payment and product dispensing system


Technologies Used

- **HTML5** – Structure of the web interface  
- **CSS3** – Styling and responsive design  
- **JavaScript** – Logic, interactivity, and automation  
- **QR Simulation** – Payment interface simulation  
- **Card Validation (JS)** – Basic validation of card details  


⚙️ Features

- 🛒 Select products (Umbrella / Raincoat)
- ➕ Increase or decrease quantity
- 💰 Auto-updating total price
- 📱 QR & Card payment options
- 🔐 Fake OTP/payment success simulation
- 📦 Stock management system
- ⏳ Countdown timer before dispensing
- 🎉 Success and thank-you message
- 🔊 Sound effects for better UI experience (optional enhancement)


🔄 Workflow

1. User selects product (Umbrella or Raincoat)
2. User sets quantity
3. Total price updates automatically
4. User selects payment method (QR/Card)
5. Payment is validated (simulation)
6. OTP confirmation (fake system)
7. Machine starts countdown
8. Product is dispensed
9. Thank you message displayed
